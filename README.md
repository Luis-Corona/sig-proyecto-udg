# SIG – Sistema Integral de Gestión  
Proyecto académico desarrollado para la materia Proyecto 7 

---

## 📌 Descripción del proyecto  
El **SIG (Sistema Integral de Gestión)** es una plataforma web diseñada para centralizar, organizar y controlar información institucional o empresarial dentro de un sistema digital accesible y eficiente.  
El proyecto surge a partir del análisis y planteamiento de una problemática web real, tomando como base los procesos vistos en los ciclos anteriores de Proyecto Web.

Este repositorio contiene **Frontend (Vue.js)** y **Backend (Laravel)** trabajando como dos módulos independientes pero integrados.

---

## 🚀 Tecnologías utilizadas

### **Frontend**
- Vue.js 3  
- Vue Router  
- Pinia (state management)  
- Vite  
- JavaScript  
- ESLint + Prettier  

### **Backend**
- PHP 8+  
- Laravel 12  
- MySQL  
- Composer
